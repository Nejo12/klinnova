# GründungsBONUS Plus — C09 Equipment / Material Investment Evidence

**Status:** F6Q working evidence record — application preparation only  
**Date:** 2026-08-25

## 1. Purpose

Assess the current **EUR 2,500 C09 equipment/material-investment planning amount** against current public market pricing and the stricter requirement that every item must be demonstrably necessary for the future funded Klinnova project.

This record does not authorize any purchase, reservation, order, contract, financing arrangement or other project commencement.

## 2. Controlling principle

For C09, **market price alone is insufficient**.

A final equipment line requires all of the following:

- exact item/specification;
- concrete funded-project purpose;
- explanation why the item is necessary rather than merely convenient;
- confirmation that an adequate equivalent is not already available to Klinnova for the project;
- current price evidence or non-binding quote;
- VAT treatment;
- acquisition timing after the permitted project boundary;
- final programme-eligibility review.

No equipment should remain in the application merely to preserve the nominal EUR 40,000 project envelope.

## 5. Necessity test

Before any C09 item can move from `PENDING` to `INCLUDE`, answer:

1. What funded-project task cannot reasonably be performed without this item?
2. Is an adequate equivalent already owned, available or otherwise usable for Klinnova?
3. Is the proposed specification proportionate to the project need?
4. Is the item primarily business/project equipment rather than private/general-purpose consumption?
5. Is the item being acquired only after the permissible project boundary?
6. Is the price supported by a current public price or non-binding quote?
7. Is VAT treatment resolved?

If any answer is weak, the item should be `REDUCE` or `EXCLUDE` rather than rationalized after the fact.

## 6. Candidate equipment architecture

Potential C09 categories that may be defensible if necessity is proven:

### E1 — primary development machine

Possible only if a dedicated project machine is genuinely necessary and an adequate equivalent is not already available.

Evidence required:

- exact configuration;
- current price comparison from at least two sources where practical;
- development/runtime justification;
- ownership/availability statement;
- expected useful project role.

### E2 — external display

Possible if required for sustained software/product/operations work and not already adequately available.

Evidence required:

- size/resolution/connectivity requirement;
- current price comparison;
- explanation of project use.

### E3 — dock/connectivity

Possible where needed to connect the selected development machine to display/network/peripherals reliably.

Evidence required:

- device compatibility;
- required ports/display support;
- current price.

### E4 — minor peripherals

Keyboard, mouse, headset, webcam or similar items should be included only when they are specifically needed for the project and not already available.

Do not create a miscellaneous-peripherals allowance.

## 7. Exclusions / weak cases

Exclude or challenge:

- replacement of functioning equipment merely because newer hardware exists;
- premium specification without project justification;
- duplicate monitors/peripherals where adequate equivalents already exist;
- private/home-entertainment equipment;
- furniture or decor without a clear programme-supported project purpose;
- items purchased before the permitted boundary;
- vague `equipment package` amounts without itemized evidence.

## 9. Recommended final-treatment rule

Do not attempt to defend EUR 2,500 merely because it was part of the original EUR 40,000 architecture.

Preferred sequence:

1. freeze the exact equipment genuinely needed for the funded project;
2. remove anything already adequately available;
3. collect two or more current market comparisons where practical;
4. resolve VAT/application treatment;
5. include only the resulting evidenced amount;
6. allow the total project budget to fall below EUR 40,000 if necessary rather than inventing hardware need.
