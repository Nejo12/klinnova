## 4. Exact clarification questions

### Q1 — Application timing / completed founding

For a sole proprietor whose Gewerbeanmeldung has already been submitted and states `01.09.2026` as the commencement date, may the GründungsBONUS Plus application be submitted from 01.09.2026 if the final confirmation/Gewerbeschein from the responsible Berlin authority has not yet been received, provided the submitted Gewerbeanmeldung can be documented?

If not, which document/date does IBT treat as proof that the founding is completed for this case?

### Q2 — Existing MVP versus future funded project

Klinnova already has a working software MVP that was developed before the funding application. No historical development cost would be claimed.

Can GründungsBONUS Plus support a clearly separated future project covering market establishment, commercialisation, structured Berlin beta/customer acquisition, evidence-driven further development and operating build-up, provided all claimed measures/costs begin only after the relevant application boundary?

If yes, does IBT recommend any specific way to describe or document the pre-existing MVP versus the future funded project in the Businessplan and cost plan?

### Q3 — Activity after signed application receipt but before funding decision

Once IBT has received the legally signed application, may the applicant begin the proposed future project — for example limited employer/candidate beta acquisition or other market-establishment measures — before the funding decision, at the applicant's own financial risk, without prejudicing eligibility?

If yes, which exact receipt/acknowledgment should the applicant retain as evidence of the permissible start date?

If no, should all such external market-entry activity remain on hold until the formal Zuwendungsbescheid?

### Q4 — Founder remuneration for sole proprietor / Nebenerwerb

How should founder remuneration or founder personnel cost be treated for a non-incorporated sole proprietor operating in Nebenerwerb?

Specifically:

- can founder working time/remuneration be included as eligible personnel expenditure at all;
- if yes, what contractual/accounting evidence is required;
- how do the published founder/management caps apply to an Einzelunternehmer without a separate employment contract?

Klinnova's current base financing model assumes EUR 0 founder remuneration, so the application does not depend on founder remuneration being eligible.

### Q5 — Recurring SaaS / infrastructure / monitoring

Can project-attributable recurring operating/IT expenditure during the approved funding period be eligible where it directly supports the funded project, for example:

- application hosting;
- managed database/backend infrastructure;
- transactional e-mail services;
- monitoring/error tracking such as Sentry;
- other recurring SaaS required for the market-establishment/operating phase?

If yes, what evidence does IBT expect for these costs, and must the corresponding subscriptions/contracts be entirely new after the application boundary, or can an existing service be expanded/activated for the future funded phase if only post-application costs are claimed?

### Q6 — Innovation / sustainability / positive Berlin effect evidence

For a digital/social labour-market platform such as Klinnova, what evidence does IBT consider most useful when assessing:

- digital/social innovation;
- sustainability/social impact;
- market and growth potential;
- positive effects for Berlin?

Would a combination of documented product differentiation, Berlin labour-market data, competitor comparison, measurable beta KPIs (employers, vacancies, applications, completed interviews, confirmed hires) and a Berlin-first market-entry plan be an appropriate evidence basis?
